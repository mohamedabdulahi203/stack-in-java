# Stacks in Java — All Examples

Java source examples extracted and organized from the supplied Chapter 3 PDF. Each `example-XX` folder contains the Java source file(s) for that example.

## Examples

1. Push and print a stack (`java.util.Stack`)
2. `peek()` vs `pop()`
3. Generics (`Box<T>`)
4. Bank: undo last deposit
5. Student: undo last course
6. Reverse a string using a stack
7. `ArrayStack<T>` implementation
8. `ArrayStack` trace (requires Example 7's `ArrayStack.java`)
9. Custom `EmptyCollectionException`
10. Traverse a linked list (requires Example 12's `Node.java`)
11. Insert at front: order matters (requires Example 12's `Node.java`)
12. `Node<T>` and `LinkedStack<T>` implementation
13. `LinkedStack` trace (requires Example 12's files)
14. Bank example using `LinkedStack` (requires Example 12's files)
15. Student example using `LinkedStack` (requires Example 12's files)

## Run a standalone example

```bash
cd example-01
javac Main.java
java Main
```

For examples with dependencies, copy required source files from the referenced example folder into the same working folder before compiling, or compile them together. The original PDF is included for reference.
